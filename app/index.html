Синхронизация ПК и телефона

Журнал, сделки, watchlist, алерты и настройки калькулятора и сканера хранятся в вашем закрытом репозитории на GitHub. Ключ вводится один раз на первом устройстве, остальные подключаются QR-кодом или кодом подключения (справа).

Как получить ключ
  1. github.com → аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Expiration — 1 год. Repository access → Only select repositories → выберите журнал и сканер.
  3. Permissions → Repository permissions: Contents — Read and write, Actions — Read and write.
  4. Generate token, скопируйте и вставьте сюда. На телефоне повторите вставку (можно переслать себе в «Избранное» Telegram и удалить сообщение).

Подключить другое устройство

Телефон или второй компьютер подключается без ввода ключа: отсканируйте QR-код камерой телефона или откройте ссылку. После этого всё общее и обновляется само.

Подключить это устройство по коду

Для iPhone: приложение с экрана «Домой» не видит то, что открылось из камеры в Safari. На подключённом устройстве нажмите «Скопировать код», перешлите его себе и вставьте сюда.

Данные и алерты

Котировки обновляются сами каждый вечер после закрытия рынка США. Ручное обновление занимает 15–25 минут.

Telegram

Статус: неизвестен — подключите синхронизацию.
Как подключить
  1. В Telegram откройте @BotFather → /newbot → получите токен.
  2. Напишите своему боту /start.
  3. На GitHub в репозитории журнала: Settings → Secrets and variables → Actions → New repository secret. Имя TG_TOKEN, значение — токен бота.
  4. Нажмите «Проверить алерты сейчас»: бот пришлёт «Бот подключён».

Установить как приложение

Телефон (Android, Chrome): меню ⋮ → «Добавить на главный экран».
iPhone (Safari): «Поделиться» → «На экран Домой».
ПК (Chrome / Edge): значок установки в адресной строке.
