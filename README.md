# Торговый помощник Осипова

Сканер рынка США (капитализация от 10 млрд $) по правилам курса А. Осипова, графики, watchlist с алертами в Telegram и торговый журнал. Работает в браузере и ставится на телефон как приложение.

- `app/` — приложение (GitHub Pages).
- `scripts/update_data.py` — ежедневная загрузка котировок (MN, W, D, H4) и построение структур для сканера: развороты, ATR, RSI(14).
- `.github/workflows/build.yml` — обновление данных после закрытия рынка и публикация сайта.

Журнал, watchlist, алерты и общие настройки хранятся в отдельном закрытом репозитории `osipov-journal`. Второе устройство подключается QR-кодом или кодом подключения из «Настроек».

Не является инвестиционной рекомендацией. Графики: TradingView Lightweight Charts™ (Apache 2.0). QR-коды: qrcode-generator, Kazuhiko Arase (MIT).
